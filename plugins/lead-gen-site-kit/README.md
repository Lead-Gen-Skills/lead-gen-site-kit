# lead-gen-site-kit

Build, optimise and audit lead-generation websites the proven way.

Skills:

- `choose-niche`: score industries, check demand, build the keyword map and set a lead price.
- `build-site`: from brief to launch for a fast, static, multi-location lead-gen site, or the brief, page plan and copy for a site you build in WordPress.
- `lead-form`: a fast, one question per screen quote form with a starting price reveal, spam checks, and a backend that saves and forwards every lead.
- `optimize-images`: the image SEO pipeline (WebP, resize, curated EXIF, geotag, filenames, alt text).
- `local-seo`: Google Business Profile, reviews, citations, links and the month by month routine after launch.
- `audit-site`: score a site against the course scorecard and get a prioritised fix list, a conversion review and a claims check.
- `google-ads`: the cost per lead sum, one simple search campaign, and a weekly review.

Install in Claude Code:

```
/plugin install lead-gen-site-kit --marketplace Lead-Gen-Skills/lead-gen-site-kit
```

See the repository README for every app, and for turning on automatic updates.
