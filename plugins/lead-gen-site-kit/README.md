# lead-gen-site-kit

Build, optimise and audit lead-generation websites the proven way.

Skills:

- `build-site`: from brief to launch for a fast, static, multi-location lead-gen site.
- `lead-form`: a fast, one question per screen quote form with a starting price reveal, spam checks, and a backend that saves and forwards every lead.
- `optimize-images`: the image SEO pipeline (WebP, resize, curated EXIF, filenames, alt text).
- `local-seo`: Google Business Profile, reviews, citations and links after launch.
- `audit-site`: score a site against the course scorecard and get a prioritised fix list.

Install in Claude Code (needs access to this private repository):

```
/plugin install lead-gen-site-kit --marketplace Lead-Gen-Skills/lead-gen-site-kit
```

See the repository README for every app, and for turning on automatic updates.
